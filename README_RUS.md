# Tic-Tac-Toe API

REST API для игры в крестики-нолики против компьютера. Написан на NestJS и TypeScript.

## Стек

- Node.js
- NestJS
- TypeScript
- Vitest, Supertest (тестирование)

## Архитектура

Приложение разделено на слои:

- **Web:** контроллеры и DTO для обработки HTTP-запросов.
- **Domain:** бизнес-логика игры и алгоритм Минимакс для хода компьютера.
- **Datasource:** репозитории и работа с хранилищем.

Между слоями используются мапперы для конвертации моделей (Domain <-> Web, Domain <-> Datasource). Поддерживается несколько параллельных игр одновременно (идентификация по UUID).
